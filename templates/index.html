Description du modèle

      

        Ce réseau de Petri modélise un feu tricolore avec gestion piéton synchronisé par un séquenceur P₅.
        Le cycle feu est Rouge → Vert → Orange → Attente → Rouge.
        Le piéton peut demander le passage (T₅), traverse uniquement au rouge (T₆), puis rend le séquenceur (T₇).
        Le réseau est vivant, sûr (1-borne) et réversible.
